Using the inspector

Explore, inspect, replay.

Knowledge graph. Search for a record, then follow its directed relationships. Select a connection to inspect its exact context and sources. Double-click a node to expand its neighborhood. Table view provides the same records with keyboard access.

Ontology. Browse definitions to understand what a class or relationship means. “View instances” opens the records that use it.

Task replay. Select a run, then step or scrub through its access events. Cumulative mode shows evidence returned up to that moment. “Follow live” polls for new events; pausing never changes the running task.

What the trace means. Returned, delivered, traversed, cited, reviewer-supported, and reuse-tested are different observations. An access trace does not reveal private reasoning or prove that older evidence remains in the model’s current context.

Local by default. Exploring this inspector does not add agent events. Task traces are excluded from public ontology releases. The application loads its graph library locally.

Keyboard: / focuses search. All graph records and relationships are available in Table view. Esc closes dialogs.
