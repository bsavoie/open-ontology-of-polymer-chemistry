About

Every answer leaves the memory larger.

A research agent answers polymer questions from what this project already knows, then from open sources. What it reads is saved with its source, checked, and read first by the next question.

  • AccumulationEach answer saves the findings it read; a reviewer checks them; the next question starts from them.
  • ExpansionFindings attach to the polymers they describe, so the ground the ontology covers keeps spreading.
